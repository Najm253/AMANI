# AMANI — Android MVP+ v1.1

تطبيق متجر Android تجريبي لعرض المنتجات السودانية، بواجهة عربية وهوية تجمع التراث والحداثة.

## ما الجديد
- بحث عن المنتجات.
- تصفية حسب الأقسام.
- مفضلة المنتجات.
- سلة مع زيادة/نقصان الكمية وحساب الإجمالي.
- تسجيل طلب محلي وعرض حالته.
- صفحة حساب المستخدم وحفظ الاسم محلياً.
- الحفاظ على هوية AMANI اللونية والزخارف النصية.

## التشغيل
افتح مجلد المشروع `AMANI-Android` في Android Studio ثم اختر Build > Build APK(s).

> الدفع الإلكتروني، قاعدة بيانات سحابية، تسجيل الدخول الحقيقي، التوصيل، وإدارة المنتجات تحتاج ربط خدمات خلفية في مرحلة لاحقة.
